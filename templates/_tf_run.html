{# Running one Terraform stack, and watching it, in a window over the page. Same shape as the Ansible run window: it POLLs `/terraform/run/{id}.json?since=N` once a second and stops when the run says `done`. Four actions instead of two — init, plan, apply, destroy. `init`/`plan` change nothing and run on a click; `apply`/`destroy` change real infrastructure, carry a confirm, and on a production stack need the stack's name typed. The whole bar is gated by the escalating `terraform_apply` permission, and apply/destroy additionally by the installation's `allow_apply` switch. #}
