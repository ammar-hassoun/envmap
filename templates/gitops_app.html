{# ── the application's own settings ──────────────────────────────────── Argo CD's automated-sync policy, which is the setting people come to this page looking for: an application with auto-sync off applies nothing until somebody syncs it. `automated=False` sends null rather than an empty object, because an empty `automated: {}` still reads as ON to the controller — see gitops.set_sync_policy. #}
automated sync
Off means nothing reaches the cluster until somebody presses Sync — which is what you want for an application you release deliberately, and not what you want for everything else.
while automated
A live edit to a managed object is reverted on the next reconcile. It is why an edit made here can disappear, and that is the setting behind it.
Without it, removing something from git leaves it running in the cluster for ever.
This writes Argo CD's own spec.syncPolicy through the controller, so it is the same change its UI makes — and it is audited.
