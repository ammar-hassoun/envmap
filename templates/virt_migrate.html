        Transfer network and other options: the full form
        A running VM moves without stopping. A VM that is powered off moves too: EnvMap copies its disks with two small helper machines of its own, reads every byte back, and never starts the VM. A VM on Proxmox moves with no sign-in, and so does any VM that is powered off. A running VM on a standalone ESXi host is started from inside, so EnvMap signs in to it: save one sign-in for a host's VMs and it is not asked again (it is stored encrypted with the connection, see Settings → Hypervisors). A network is chosen for you only when it is certain: the network of the same name, the only one there is, or the one you chose last time for these two hosts. Moving needs “Hypervisors: administer” on both hosts, and each must allow management from EnvMap.
