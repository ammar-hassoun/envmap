WHY A TOKEN IS A CARD AND NOT A TABLE ROW It was a nine-column table with the scope editor in a ``. Two things went wrong and both were structural. The editor is forty checkboxes, and a table cell does not reserve height for what a `
` inside it unfolds — measured: 971 overlapping element pairs, the editor's labels sitting on top of every row beneath it. And nine columns do not fit a laptop, so the last of them was simply cut off. A card owns its own height and grows downwards, so an editor inside one cannot land on anything else. The information is the same; the geometry is the difference between a page that reads and a page that smears. `back` is which page to return to; `may_manage` is whether this person holds Cluster management at all, because offering a token the ability to act when its owner cannot is offering a refusal. -#} {% macro chips(name, items, chosen, cols=2) %} {#- A checkbox that reads as a chip: the whole pill is the hit area and it lights up when it is on, so a scope can be read at a glance instead of hunting for ticked boxes down a column of identical squares. -#}
