WHY THIS IS A LIST AND NOT A STACK OF FORMS Every cluster used to render its whole edit form — name, two textareas, context, the management tick, two buttons — expanded, always. WHY THERE IS NO SEPARATE "ENVIRONMENT → CLUSTER" CARD ANY MORE There used to be one — a grid of every environment in every region with a dropdown each, shown deliberately alongside the cluster rows' own chips so the same fact read from both directions. It was requested away: with twenty-plus environments across a handful of regions it was a second big always-open surface competing with the cluster list for attention, and a cluster's own "serves environment" field already does the assignment. What that card ALSO carried — declaring/undeclaring an environment, scanning a repo for candidates, adding a region — moved into a small per-project panel (`env_admin`, opened like "add a cluster", not rendered open by default) rather than disappearing; the one thing genuinely gone is the cross-project "N unmapped" tally, which had nowhere honest left to point once the grid was gone.
