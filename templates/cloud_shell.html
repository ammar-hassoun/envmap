What this is, and is not Cloud Assistant

This is not an interactive terminal. Alibaba's API has no session to attach to, so a command is submitted to the instance's Cloud Assistant agent and its output collected — which suits an audited portal better than a terminal would: every command run here is recorded with who ran it, before it runs.

The agent runs as root. It is preinstalled on recent images; an older one needs it installed first. A command that waits for input will hit its timeout with nothing to show, so pass flags like -y rather than answering prompts.
