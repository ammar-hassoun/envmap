What gets sent, and what never does

Each question sends two things: the question itself, and a briefing describing this estate. The briefing is rebuilt per request from the live database and filtered by the asking person's roles — someone who cannot see a project in the UI cannot learn about it here either.

Credentials are never sent. The briefing is assembled from named fields — names, URLs, counts, statuses — and never from whole connection rows, so tokens, passwords, kubeconfigs and sealing certificates cannot reach it. As a backstop the portal compares the finished briefing against every stored secret and refuses to send it if one appears. The assistant also has no way to act: no commands, no commits, no changes.
